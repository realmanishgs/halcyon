# Testing

Every claim in FEATURE_MATRIX.md maps to one of the checks below. Media is synthetic and license-free
(FFmpeg lavfi `testsrc2` / `sine`); real-world files go in `test-media/corpus/` and are picked up
automatically. All of `test-media/` is gitignored and regenerated by the scripts.

## 1. Unit + engine integration tests (always on, ~3 s)

```bash
bash scripts/make-test-media.sh
```

```bash
cd src-tauri && cargo test --lib
```

22 tests, real libVLC with `--aout=adummy --vout=vdummy` (silent, headless, decoders run for real):
per-format play/seek/pause (H.264, HEVC10/E-AC-3, VP9, AV1, MPEG-2 TS, MP3, 5.1 WAV, FLAC tags, Unicode
name), multi-track switching, rate, garbage and truncated input, `pause_then_resume`,
`play_and_seek_after_end`, `path_over_260_chars_plays`, verbatim-path normalisation, M3U/PLS/XSPF
parsing and path resolution, and `wm_dropfiles_reaches_sink_with_unicode_paths` (builds a real Win32
`HDROP` and delivers `WM_DROPFILES`, wheel and double-click to the native video surface).

**Result 2026-11-08:** 22 passed, 0 failed.

## 2. Stress suite (opt-in, ~2 min)

```bash
bash scripts/make-stress-media.sh
```

```bash
cd src-tauri && cargo test --lib stress -- --ignored --nocapture --test-threads=1
```

`make-stress-media.sh` builds 79 files with an expectation each (`test-media/formats/EXPECT.tsv`:
`play`, `partial`, `unsupported`), plus damaged/odd files and playlists. The test reuses one engine for
everything (itself a stability test) and writes `test-media/STRESS_REPORT.md`.

- **Format matrix** — `play` must reach Playing, produce decoder output for every declared stream type
  (libVLC `media_stats` counters), and land a seek to 50 %. Also recorded: input-start and first-output
  latency, engine-visible audio/subtitle tracks, lost frames.
- **Robustness** — zero-byte, random bytes, truncated, corrupted-middle, wrong extension, `#%[]&'{}`
  name, emoji/CJK name, 388-character path. Must never hang (12 s cap) or crash.
- **Engine torture** — 80 rapid opens 25 ms apart, 200 random seeks on 4K60, 100 pause toggles, rate
  sweep 0.25–4×, 30 live track switches, external SRT/ASS/VTT while playing, audio/subtitle delay,
  chapter jump, 3-hour file seek to 2:59:00, memory over 100 open/stop cycles, all playlist types,
  folder scan.

**Result 2026-11-08 (libVLC 3.0.24, ffprobe 9.0.1):** 79 formats → 71 pass, 4 partial (IAMF `.iamf`:
one substream only), 4 unsupported as documented (VVC video, IAMF-in-MP4, raw aptX, MIDI without
SoundFont), **0 unexpected failures**; 8/8 robustness; 17/17 torture checks; memory 156 → 122 MB.

Bugs this suite found and fixed: libVLC 3 cannot open paths ≥ 260 chars (now opened via 8.3 short
name); playlist-relative `..` paths leaked into titles (now canonicalised); IAMF had been
"passing" while only one substream decodes (now classified partial, with an in-app banner).

## 3. Hardware decoding

```bash
bash scripts/hw-decode-check.sh
```

Plays hi-res fixtures through `vlc.exe` (same libVLC + plugins) with D3D11VA requested and reads VLC's
log. **Result:** "Using D3D11VA (Intel Arc 140T …) for hardware decoding" for H.264 1080p, H.264 4K60,
HEVC Main10 4K HDR10, VP9 Profile 2 4K and AV1 8K → `test-media/HW_DECODE.md`.

## 4. Manual UI verification in the running app (recorded 2026-11-08)

Driven with real mouse/keyboard input (SendInput/SendKeys) and window captures:

| Check | Result |
|---|---|
| Pause → play (button and Space) | resumes; frame counter advances |
| Play after end; `0` after end | restarts from 0 (was broken: libVLC ignores play/seek after end) |
| `5` jumps to 50 %; drag seek bar and release *outside* it | lands at 0:10 / 0:14; no stuck scrub |
| Playhead vs frame timestamp | label matches the burned-in timecode (1.3 s ↔ 0:01, 2.9 s ↔ 0:02) |
| Double-click video → fullscreen; controls auto-hide after 2.5 s; mouse move reveals; Esc exits | ✓ (fullscreen surface sizes itself above the visible controls) |
| Wheel over video | volume ±5 per notch, toast shown |
| Right-click video | native menu above video: speed, audio track, subtitles, aspect, deinterlace, snapshot, open… |
| Window resized 1300 / 900 / 640 px wide | sidebar → icon rail → hidden; transport compacts; mini-player at 640 × 460 |
| File + playlist on command line | queue of 4, auto-advance at end, sidecar SRT auto-loaded and rendered |
| Info panel on 4K HDR10 | badges `HDR10 / PQ`, `4K`, `Dolby Digital Plus`; live decoder stats |

Bugs found here and fixed: playhead snapping back after seek and freezing when a drag ended outside the
bar (new SeekBar with pointer capture + pending-seek hold); play/seek doing nothing after the end; Space
double-firing on a focused button; `&` rendered as a mnemonic in the native menu; fullscreen video
covering the control bar (a window region can't clip libVLC's D3D11 swapchain).
