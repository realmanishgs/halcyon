Halcyon
Halcyon is a lightweight media player built on top of libVLC, offering a clean interface and smooth support for custom skins on its miniplayer view.
Features
 * Skin Support: Customize the miniplayer layout and appearance using custom-built interface skins.
 * Built on libVLC: Powered by the stable and versatile libVLC core for comprehensive format compatibility and playback performance.
 * Lightweight Interface: Designed to be fast, minimal, and resource-efficient.
Getting Started
Prerequisites
To compile and run Halcyon, ensure you have the required libVLC development headers and runtime libraries available on your system:
 * Windows: Install the VLC media player binaries or the appropriate SDK so the required libVLC DLLs can be located.
 * Linux: Install the development package via your package manager (e.g., sudo apt install libvlc-dev).
 * macOS: Install VLC and confirm the framework paths are correctly linked.
Building from Source
Clone the repository and compile using your preferred build toolchain:
git clone https://github.com/realmanishgs/halcyon.git
cd halcyon
